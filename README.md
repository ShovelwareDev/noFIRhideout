# No FIR Hideout for SPT

A lightweight server mod for SPT that removes the **Found in Raid (FIR)** requirement for all hideout station item requirements. 

## Features
- Automatically strips the `IsSpawnedInSession` check from all hideout requirements on server startup.
- Allows you to use non-FIR items, crafted items, or flea market purchases for hideout upgrades.

## Compatibility
- Targets SPT **~4.1.6**
